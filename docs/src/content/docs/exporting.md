The export menu turns the active CV into files you can use outside the app.

## PDF

Use PDF for job applications, email attachments, and final documents.

PDF export renders from the same sections used by the preview. If the preview has validation errors, fix them before exporting.

Native PDF sharing uses the Web Share API when available. If native sharing is unavailable or cancelled, the app falls back to downloading a PDF.

## Typst

Typst export is useful when you want to inspect or continue editing the generated document source outside the app.

Use Typst export for:

- Debugging rendering issues.
- Archival source output.
- Advanced local customization.

## JSON

JSON export converts the CV YAML content into structured JSON.

Use it for:

- Integrations.
- Data inspection.
- Custom scripts.

The backup/share file is different from CV JSON: it stores all four YAML sections plus app metadata needed for re-import.

## Markdown

Markdown export converts CV content into a readable text format.

Use it for:

- Profile drafts.
- Plain-text review.
- Copying into systems that accept Markdown.

## Share File

Share files preserve the CV sections for later import into the app. Use them when URL sharing would be too large or when you want a file-based backup.

The share/export dialog also supports importing backup files and importing review proposal packages.

## Download All Data

The sidebar can export all local CV data as `CVs.zip`. The zip includes active files and grouped archive/trash files.

Use this before clearing browser data, changing machines, or doing major cleanup.

## Export Checklist

Before sending a CV:

1. Preview every page.
2. Check links and email addresses.
3. Confirm hidden entries are intentional.
4. Export PDF.
5. Reopen the PDF in a separate viewer.
